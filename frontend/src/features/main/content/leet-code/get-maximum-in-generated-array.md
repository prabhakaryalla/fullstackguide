# 1646. Get Maximum in Generated Array

**Difficulty:** Easy
**Category:** Array, Simulation

## Problem

An array `nums` of length `n + 1` is generated by the rules: `nums[0] = 0`, `nums[1] = 1`, `nums[2*i] = nums[i]` for `2 <= 2*i <= n`, and `nums[2*i + 1] = nums[i] + nums[i + 1]` for `2 <= 2*i+1 <= n`. Return the maximum value in `nums`.

### Example

```
Input: n = 7
Output: 3
```

## Approach

Build the array iteratively following the recurrence directly (each new value only depends on previously computed smaller indices), then take the maximum. Handle `n == 0` as a special case since the array would only contain `nums[0] = 0`.

## C# Solution

```csharp
public class Solution
{
    public int GetMaximumGenerated(int n)
    {
        if (n == 0)
        {
            return 0;
        }

        int[] nums = new int[n + 1];
        nums[1] = 1;

        for (int i = 2; i <= n; i++)
        {
            nums[i] = i % 2 == 0 ? nums[i / 2] : nums[i / 2] + nums[i / 2 + 1];
        }

        return nums.Max();
    }
}
```

## Complexity

- **Time:** `O(n)`.
- **Space:** `O(n)`.
