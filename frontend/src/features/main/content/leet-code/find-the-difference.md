# 389. Find the Difference

**Difficulty:** Easy
**Category:** Hash Table, String, Bit Manipulation, Sorting

## Problem

Given two strings `s` and `t` where `t` is generated by shuffling `s` and adding one extra letter, return the extra letter added to `t`.

### Example

```
Input: s = "abcd", t = "abcde"
Output: "e"
```

### Constraints

- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.

## Approach

XOR every character of both strings together. Characters that appear in both `s` and `t` cancel each other out (since XOR is self-inverse), leaving only the one extra character in `t` that has no matching pair.

## C# Solution

```csharp
public class Solution
{
    public char FindTheDifference(string s, string t)
    {
        char result = '\0';
        foreach (var c in s) result ^= c;
        foreach (var c in t) result ^= c;

        return result;
    }
}
```

## Complexity

- **Time:** `O(n)` — one pass over each string.
- **Space:** `O(1)`.
