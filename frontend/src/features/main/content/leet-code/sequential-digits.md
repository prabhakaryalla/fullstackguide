# 1291. Sequential Digits

**Difficulty:** Medium
**Category:** Array, Backtracking, Enumeration

## Problem

Given two positive integers `low` and `high`, return a sorted list of all "sequential digit" numbers in the range `[low, high]` — numbers whose digits form a strictly increasing run of consecutive digits (like `123` or `5678`).

### Example

```
Input: low = 100, high = 300
Output: [123,234]
```

## Approach

Every sequential-digit number is a contiguous substring of the fixed string `"123456789"`. Generate all such substrings of every possible length (from `2` digits up to `9`), parse each as an integer, and keep the ones that fall within `[low, high]`. Since substrings are generated by increasing starting position and length, a final sort produces the required ascending order (the growth in length dominates, so sorting is a simple safeguard).

## C# Solution

```csharp
public class Solution
{
    public IList<int> SequentialDigits(int low, int high)
    {
        var result = new List<int>();
        const string digits = "123456789";

        for (int length = 2; length <= 9; length++)
        {
            for (int start = 0; start + length <= 9; start++)
            {
                int num = int.Parse(digits.Substring(start, length));
                if (num >= low && num <= high)
                    result.Add(num);
            }
        }

        result.Sort();
        return result;
    }
}
```

## Complexity

- **Time:** `O(1)` — at most 36 candidate numbers are ever generated.
- **Space:** `O(1)` beyond the output.
